## Codebase Patterns
- OpportunityScan.tsx contains both `OpportunityScan` and `KatoQueue` components plus all SVG icons
- All SVG icons are defined as inline function components at the bottom of OpportunityScan.tsx
- Dark theme uses `bg-[#111111]` for card backgrounds, `bg-[#0a0a0a]` for section containers
- Border pattern: `border border-white/[0.06]` for subtle borders, `hover:border-white/[0.1]` for hover
- Type color mapping: blocker=rose, ready=emerald, deadline=amber, opportunity=cyan, suggestion=gray
- Priority color mapping: high=rose, medium=amber, low=gray
- Agent color mapping: kato=cyan, yuki=violet, koji=amber, sora=emerald, karin=rose (AGENT_COLORS const)
- MissionControl.tsx is the main page component that orchestrates all sections
- `useDashboardData` hook handles API fetch with polling (5s) and JSON fallback
- Progress bars use `h-1` or `h-1.5` with `bg-white/[0.06]` track and colored fill with rounded-full
